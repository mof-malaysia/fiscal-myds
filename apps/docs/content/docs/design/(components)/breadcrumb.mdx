---
title: Breadcrumb
description: A navigation aid that helps users understand their current location within a website or application and allows them to easily navigate back to previous levels.
---

![breadcrumb-anatomy.png](/design/breadcrumb-anatomy.png)

The key elements that define a Breadcrumb’s structure and function.

1. **Parent Page**: Links to the preceding page or section, helping users navigate back through the hierarchy.
2. **Current Page**: Indicates the user’s current location in the navigation path, typically not clickable.
3. **Trail**: The ordered list that holds the crumbs, separated by small chevrons. It sits directly in the layout with no background, border or container around it; it only keeps spacing and alignment consistent.

## Limit title length

![breadcrumb-overflow-ellipsis.png](/design/breadcrumb-overflow-ellipsis.png)

1. **Limit Title Length**: Each crumb, parent or current page, has a maximum width of 200px. If a title exceeds this length, it is truncated with an ellipsis (e.g., "Long Page Title...") to maintain a clean and organized layout. The full title stays available as a tooltip on hover.

## Collapse deep trails

For deep hierarchies, keep the first level and the last two, and replace the levels in between with an ellipsis ("…"). The ellipsis is decorative; if users need to reach the hidden levels, place it inside a button or menu that lists them.
