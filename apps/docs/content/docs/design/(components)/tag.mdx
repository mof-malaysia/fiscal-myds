## Status tag type

![tag-status-type.png](/design/tag-status-type.png)

1. **Gray**: Default status tag.
2. **Brand**: Indicates a tag related to a product's brand.
3. **Success**: Represents a successful status or outcome.
4. **Danger**: Indicates a critical issue or error.
5. **Warning**: Alerts the user to a potential issue or cautionary state.

## Style

Tags have one style: a pill (9999px radius) with a wash background, matching coloured text in Medium weight, and no border. The same shape works on its own, on an image, or inline with text. The words carry the meaning, so status never rests on colour alone.

## Size

![tag-size.png](/design/tag-size.png)

Sizes follow the page density (comfortable for citizen services, compact for officer tools), not the device.

**Small**: The 13px badge (22px tall, 10px side padding), for tables and dense lists in either density.

**Medium** (default): 14px and 24px tall in comfortable density; the 13px badge in compact.

**Large**: 16px and 32px tall, for citizen-facing emphasis; 14px in compact.

## Status dot (Optional)

![tag-status-dot.png](/design/tag-status-dot.png)

1. **Dot**: The optional status dot provides a visual indicator to represent the current state or status of an item.
   - Small = 6x6
   - Medium = 6x6
   - Large = 8x8
