### Steps to install

<Steps>
  <Step>
    #### Create a Laravel project with React

    ```sh title="terminal"
    laravel new project-name --react
    ```

    The React starter kit sets up Inertia, Vite, Tailwind CSS v4 and the `@/` import alias (pointing at `resources/js`). Then head to the project root:

    ```sh title="terminal"
    cd project-name
    npm install && npm run build
    ```

  </Step>

  <Step>
    #### Switch shadcn to Base UI

    The starter kit ships shadcn components built on Radix. MYDS is built on Base UI, so switch the project's shadcn configuration:

    ```package-install
    npx shadcn@latest init --base base --force
    ```

    <Callout
      type="info"
      title="Important"
      className="bg-bg-primary-50 text-txt-primary border-transparent"
      icon={<InfoIcon className="size-5" />}
    >
      The starter kit's own pages (login, settings, etc.) use its shadcn components. After switching, and after MYDS replaces components with the same name (such as `button`, `dialog` and `checkbox`), some of those pages may need updating. Run `npx tsc --noEmit` to find them.
    </Callout>

  </Step>

  <Step>
    #### Install the MYDS styles

    ```package-install
    npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/style/styles/default/myds-init.json
    ```

    This creates `styles/myds.css` in the project root.

  </Step>

  <Step>
    #### Configure CSS stylesheet

    Add the MYDS fonts at the very top of `resources/css/app.css`, and import `styles/myds.css` right after Tailwind.

    ```css title="resources/css/app.css"
    @import url("https://fonts.googleapis.com/css2?family=Inter:ital,opsz,wght@0,14..32,100..900;1,14..32,100..900&family=Poppins:ital,wght@0,400;0,500;0,600;1,400;1,500;1,600&display=swap"); /* [!code ++] */
    @import "tailwindcss";
    @import "../../styles/myds.css"; /* [!code ++] */
    ```

    Please read the [Style Configuration](./style-configuration) for more advanced configuration.

  </Step>

  <Step>
    #### Add components

    ```package-install
    npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/button.json --overwrite
    ```

    Components are added to `resources/js/components/ui`. `--overwrite` replaces the starter kit's component of the same name.

  </Step>

  <Step>
    #### Start using the components!

    Use the components in your Inertia `Pages` components:

    ```tsx title="resources/js/pages/welcome.tsx"
    import { Head } from "@inertiajs/react";
    import { Button } from "@/components/ui/button";

    export default function Welcome() {
      return (
        <>
          <Head title="Welcome" />
          <Button variant="primary-fill">Hello MYDS</Button>
        </>
      );
    }
    ```
    </Step>

</Steps>
