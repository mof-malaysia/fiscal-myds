### Panduan Pemasangan

<Steps>
  <Step>
    #### Bina projek Laravel dengan React

    ```sh title="terminal"
    laravel new nama-projek --react
    ```

    Kit permulaan React menetapkan Inertia, Vite, Tailwind CSS v4 dan alias import `@/` (merujuk kepada `resources/js`). Kemudian pergi ke induk projek:

    ```sh title="terminal"
    cd nama-projek
    npm install && npm run build
    ```

  </Step>

  <Step>
    #### Tukar shadcn kepada Base UI

    Kit permulaan disertakan dengan komponen shadcn yang dibina di atas Radix. MYDS dibina di atas Base UI, jadi tukar konfigurasi shadcn projek:

    ```package-install
    npx shadcn@latest init --base base --force
    ```

    <Callout
      type="info"
      title="Penting"
      className="bg-bg-primary-50 text-txt-primary border-transparent"
      icon={<InfoIcon className="size-5" />}
    >
      Halaman kit permulaan (log masuk, tetapan, dll.) menggunakan komponen shadcn kit tersebut. Selepas penukaran, dan selepas MYDS menggantikan komponen dengan nama yang sama (seperti `button`, `dialog` dan `checkbox`), sesetengah halaman mungkin perlu dikemas kini. Jalankan `npx tsc --noEmit` untuk mengenal pasti halaman tersebut.
    </Callout>

  </Step>

  <Step>
    #### Pasang gaya MYDS

    ```package-install
    npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/style/styles/default/myds-init.json
    ```

    Arahan ini mencipta `styles/myds.css` di induk projek.

  </Step>

  <Step>
    #### Konfigurasi stylesheet CSS

    Tambah fon MYDS di bahagian paling atas `resources/css/app.css`, dan import `styles/myds.css` sejurus selepas Tailwind.

    ```css title="resources/css/app.css"
    @import url("https://fonts.googleapis.com/css2?family=Inter:ital,opsz,wght@0,14..32,100..900;1,14..32,100..900&family=Poppins:ital,wght@0,400;0,500;0,600;1,400;1,500;1,600&display=swap"); /* [!code ++] */
    @import "tailwindcss";
    @import "../../styles/myds.css"; /* [!code ++] */
    ```

    Sila baca [Konfigurasi Gaya](./style-configuration) untuk konfigurasi lanjutan.

  </Step>

  <Step>
    #### Tambah komponen

    ```package-install
    npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/button.json --overwrite
    ```

    Komponen ditambah ke `resources/js/components/ui`. `--overwrite` menggantikan komponen kit permulaan yang mempunyai nama yang sama.

  </Step>

  <Step>
    #### Mula menggunakan komponen!

    Gunakan komponen dalam komponen `Pages` Inertia anda:

    ```tsx title="resources/js/pages/welcome.tsx"
    import { Head } from "@inertiajs/react";
    import { Button } from "@/components/ui/button";

    export default function Welcome() {
      return (
        <>
          <Head title="Welcome" />
          <Button variant="primary-fill">Hello MYDS</Button>
        </>
      );
    }
    ```
    </Step>

</Steps>
