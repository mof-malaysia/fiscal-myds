### Panduan Pemasangan

<Steps>
  <Step>
    #### Bina projek Next.js

    CLI shadcn boleh membina projek Next.js yang telah ditetapkan dengan Tailwind CSS v4, alias import `@/` dan Base UI.

    ```package-install
    npx shadcn@latest init -t next -n nama-projek
    ```

    Selepas projek dibuat, pergi ke induk projek:
    ```sh title="terminal"
    cd nama-projek
    ```

    Sudah mempunyai projek Next.js dengan Tailwind CSS? Jalankan `npx shadcn@latest init` di induk projek tersebut.

  </Step>

  <Step>
    #### Pasang gaya MYDS

    ```package-install
    npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/style/styles/default/myds-init.json
    ```

    Arahan ini mencipta `styles/myds.css` di induk projek.

  </Step>

  <Step>
    #### Konfigurasi stylesheet CSS

    Tambah fon MYDS di bahagian paling atas `app/globals.css`, dan import `styles/myds.css` sejurus selepas Tailwind.

    ```css title="app/globals.css"
    @import url("https://fonts.googleapis.com/css2?family=Inter:ital,opsz,wght@0,14..32,100..900;1,14..32,100..900&family=Poppins:ital,wght@0,400;0,500;0,600;1,400;1,500;1,600&display=swap"); /* [!code ++] */
    @import "tailwindcss";
    @import "../styles/myds.css"; /* [!code ++] */
    ```

    Sila baca [Konfigurasi Gaya](./style-configuration) untuk konfigurasi lanjutan.

  </Step>

  <Step>
    #### Tambah komponen

    ```package-install
    npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/button.json --overwrite
    ```

    `--overwrite` menggantikan `components/ui/button.tsx` yang dicipta oleh `shadcn init` dengan butang MYDS. Komponen lain hanya memerlukan URL, contohnya `.../registry/ui/styles/default/dialog.json`.

  </Step>

  <Step>
    #### Mula menggunakan komponen!

    Cubalah `<Button />` untuk memulakan membina dengan MYDS!

    ```tsx title="components/hello-button.tsx"
    "use client"; // [!code highlight] Untuk Next App Router, mesti sertakan baris ini
    import { Button } from "@/components/ui/button";

    export default () => {
      return <Button variant="primary-fill">Hello MYDS</Button>;
    };
    ```

    <Callout
      type="info"
      title="Penting"
      className="bg-bg-primary-50 text-txt-primary border-transparent"
      icon={<InfoIcon className="size-5" />}
    >
      Komponen MYDS dibina untuk wujud di _client_, manakala Next.js App Router, secara lalai, membina komponen di _server_.

      Untuk menetapkan komponen supaya dibina di _client_ dalam Next.js, anda perlu menyertakan arahan `use client` dalam fail komponen.
      Manakala untuk Next.js Page Router, anda boleh mengabaikan arahan ini.
    </Callout>

    ```tsx title="app/page.tsx"
    import HelloButton from "@/components/hello-button";

    export default function Home() {
      return (
        <div>
          <HelloButton />
        </div>
      );
    }
    ```
    </Step>

</Steps>
