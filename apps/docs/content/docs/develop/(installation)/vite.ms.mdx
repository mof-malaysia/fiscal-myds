### Panduan Pemasangan

<Steps>
  <Step>
    #### Bina projek Vite

    CLI shadcn boleh membina projek Vite + React + TypeScript yang telah ditetapkan dengan Tailwind CSS v4, alias import `@/` dan Base UI.

    ```package-install
    npx shadcn@latest init -t vite -n nama-projek
    ```

    Selepas projek dibuat, pergi ke induk projek:
    ```sh title="terminal"
    cd nama-projek
    ```

  </Step>

  <Step>
    #### Pasang gaya MYDS

    ```package-install
    npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/style/styles/default/myds-init.json
    ```

    Arahan ini mencipta `styles/myds.css` di induk projek.

  </Step>

  <Step>
    #### Konfigurasi stylesheet CSS

    Tambah fon MYDS di bahagian paling atas `src/index.css`, dan import `styles/myds.css` sejurus selepas Tailwind.

    ```css title="src/index.css"
    @import url("https://fonts.googleapis.com/css2?family=Inter:ital,opsz,wght@0,14..32,100..900;1,14..32,100..900&family=Poppins:ital,wght@0,400;0,500;0,600;1,400;1,500;1,600&display=swap"); /* [!code ++] */
    @import "tailwindcss";
    @import "../styles/myds.css"; /* [!code ++] */
    ```

    Sila baca [Konfigurasi Gaya](./style-configuration) untuk konfigurasi lanjutan.

  </Step>

  <Step>
    #### Tambah komponen

    ```package-install
    npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/button.json --overwrite
    ```

    `--overwrite` menggantikan `src/components/ui/button.tsx` yang dicipta oleh `shadcn init` dengan butang MYDS.

  </Step>

  <Step>
    #### Mula menggunakan komponen!

    Cubalah `<Button />` untuk memulakan membina dengan MYDS!

    ```tsx title="src/App.tsx"
    import { Button } from "@/components/ui/button";

    function App() {
      return (
        <Button variant="primary-fill">
          Hello MYDS
        </Button>
      );
    }

    export default App;
    ```

  </Step>

</Steps>
