### Steps to install

<Steps>
  <Step>
    #### Create a Next.js project

    The shadcn CLI can create a Next.js project with Tailwind CSS v4, the `@/` import alias and Base UI already configured.

    ```package-install
    npx shadcn@latest init -t next -n project-name
    ```

    After the project is created, head to the project root:
    ```sh title="terminal"
    cd project-name
    ```

    Already have a Next.js project with Tailwind CSS? Run `npx shadcn@latest init` in its root instead.

  </Step>

  <Step>
    #### Install the MYDS styles

    ```package-install
    npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/style/styles/default/myds-init.json
    ```

    This creates `styles/myds.css` in the project root.

  </Step>

  <Step>
    #### Configure CSS stylesheet

    Add the MYDS fonts at the very top of `app/globals.css`, and import `styles/myds.css` right after Tailwind.

    ```css title="app/globals.css"
    @import url("https://fonts.googleapis.com/css2?family=Inter:ital,opsz,wght@0,14..32,100..900;1,14..32,100..900&family=Poppins:ital,wght@0,400;0,500;0,600;1,400;1,500;1,600&display=swap"); /* [!code ++] */
    @import "tailwindcss";
    @import "../styles/myds.css"; /* [!code ++] */
    ```

    Please read the [Style Configuration](./style-configuration) for more advanced configuration.

  </Step>

  <Step>
    #### Add components

    ```package-install
    npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/button.json --overwrite
    ```

    `--overwrite` replaces the `components/ui/button.tsx` that `shadcn init` created with the MYDS button. Other components only need the URL, e.g. `.../registry/ui/styles/default/dialog.json`.

  </Step>

  <Step>
    #### Start using the components!

    Here is a `<Button />` for you to get started!

    ```tsx title="components/hello-button.tsx"
    "use client"; // [!code highlight] For Next App Router, must include this line
    import { Button } from "@/components/ui/button";

    export default () => {
      return <Button variant="primary-fill">Hello MYDS</Button>;
    };
    ```

    <Callout
      type="info"
      title="Important"
      className="bg-bg-primary-50 text-txt-primary border-transparent"
      icon={<InfoIcon className="size-5" />}
    >
      MYDS components are built for the client-side, while Next.js App router is
      server rendered by default.

      To tell Next.js to render the component client side, you
      must include the `use client` directive in the component file. For Next.js Page router, you may omit the directive.
    </Callout>


    ```tsx title="app/page.tsx"
    import HelloButton from "@/components/hello-button";

    export default function Home() {
      return (
        <div>
          <HelloButton />
        </div>
      );
    }
    ```
    </Step>

</Steps>
