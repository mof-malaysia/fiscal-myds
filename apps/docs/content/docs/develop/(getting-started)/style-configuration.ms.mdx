## Asas

Selain stylesheet gabungan `myds-init`, anda boleh memasang setiap bahagian secara berasingan. Setiap bahagian ditulis ke failnya sendiri di bawah `styles/myds/`:

```package-install
npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/style/styles/default/colors.json https://mof-malaysia.github.io/fiscal-myds/registry/style/styles/default/theme-light.json https://mof-malaysia.github.io/fiscal-myds/registry/style/styles/default/theme-dark.json https://mof-malaysia.github.io/fiscal-myds/registry/style/styles/default/theme-config.json https://mof-malaysia.github.io/fiscal-myds/registry/style/styles/default/base-styles.json
```

Kemudian import bahagian yang anda perlukan sahaja, selepas `@import "tailwindcss";`, menggantikan `styles/myds.css`.


### Fon

MYDS menyokong 2 jenis fon: `Poppins` & `Inter`. Kami mengesyorkan anda untuk mengimport melalui CDN yang bereputasi seperti [GoogleFonts](https://fonts.google.com/). Berikut adalah satu baris import CSS!

```css
@import url("https://fonts.googleapis.com/css2?family=Inter:ital,opsz,wght@0,14..32,100..900;1,14..32,100..900&family=Poppins:ital,wght@0,400;0,500;0,600;1,400;1,500;1,600&display=swap");
```

### Warna

Kami mentakrifkan setiap warna dalam Bahasa Reka Bentuk MYDS sebagai pembolehubah CSS, yang kemudiannya menjadi blok binaan untuk membina tema!

```css
@import "../styles/myds/colors.css";
```

### Tema

MYDS menyokong kedua-dua mod terang dan gelap. Walau bagaimanapun, kami memahami bahawa tidak semua projek memerlukan ciri ini.
Oleh itu, anda boleh mengabaikan import tema yang tidak diingini dari projek anda!

```css
/* Import tema terang */
@import "../styles/myds/theme-light.css";

/* Import tema gelap */
@import "../styles/myds/theme-dark.css";
```

## TailwindCSS

[TailwindCSS](https://tailwindcss.com/docs/installation) adalah rangka kerja CSS berasaskan utiliti yang menjadi asas kepada cara MYDS digayakan secara dalaman.
Walau bagaimanapun, menggunakan TailwindCSS adalah pilihan di peringkat projek.

Jika anda menggunakan TailwindCSS, MYDS menyediakan pilihan untuk pembangun memanfaatkan kelas CSS yang ditakrifkan atau memperluaskan variasi anda sendiri kepada MYDS.

### Konfigurasi Tema

MYDS memerlukan Tailwind CSS v4, yang ditetapkan oleh CLI shadcn untuk anda. Tiada preset atau konfigurasi `content` yang perlu ditambah: bahagian `theme-config` (termasuk dalam `styles/myds.css`) mentakrifkan setiap token MYDS menggunakan arahan `@theme` Tailwind, dan Tailwind v4 mengesan fail komponen dalam projek anda secara automatik.

```css title="app/globals.css"
@import "../styles/myds/theme-config.css";
```

Untuk memperluaskan MYDS, tambah blok `@theme` anda sendiri dalam CSS global selepas import MYDS.

### Token Warna

MYDS mempunyai 2 jenis token warna yang perlu diketahui oleh pembangun, iaitu:

- **Token primitif** - Nilai token primitif adalah statik & tidak sensitif kepada perubahan tema.

- **Token tema** - Nilai token tema berubah berdasarkan tema yang digunakan.

Untuk mempelajari senarai penuh token primitif & tema yang tersedia, baca [konfigurasi penuh](https://github.com/mof-malaysia/fiscal-myds/blob/main/packages/style/styles/tailwind.config.css)
