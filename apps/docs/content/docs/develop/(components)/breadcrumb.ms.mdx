## Pemasangan

Tambah komponen ini ke projek anda dengan CLI shadcn. Lihat [Pemasangan](./install) untuk persediaan awal.

```package-install
npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/breadcrumb.json
```

## Penggunaan

```ts copy title="Import"
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbSeparator,
  BreadcrumbPage,
  BreadcrumbEllipsis,
} from "@/components/ui/breadcrumb";
```

```tsx copy title="Anatomi" title="Anatomi"
export default () => (
  <Breadcrumb>
    <BreadcrumbItem>
      <BreadcrumbLink />
      <BreadcrumbPage />
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbEllipsis />
    </BreadcrumbItem>
  </Breadcrumb>
);
```

## Contoh

### Pautan vs Halaman

`BreadcrumbLink` digunakan untuk halaman induk, manakala `BreadcrumbPage` digunakan untuk halaman semasa. Halaman semasa biasanya tidak boleh diklik.

  <Tab value="Pratonton">
    <div className="not-prose space-y-2">
      <Breadcrumb>
        <BreadcrumbItem>
          <BreadcrumbLink href="#home">BreadcrumbLink 1</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbLink href="#collection">BreadcrumbLink 2</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbPage>BreadcrumbPage</BreadcrumbPage>
        </BreadcrumbItem>
      </Breadcrumb>
    </div>
  </Tab>

### Serpihan Ellipsis

Serpihan yang terlalu panjang akan dipendekkan dengan elipsis. Had lebar maksimum ialah `200px`. Nama penuh disimpan dalam tooltip `title`, jadi pengguna boleh menuding pada serpihan untuk melihatnya.

<Tabs items={["Pratonton", "Kod"]} defaultValue="Pratonton">
  <Tab value="Pratonton">
    <div className="not-prose space-y-2">
      <Breadcrumb>
        <BreadcrumbItem>
          <BreadcrumbLink href="#home">Laman Utama</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbLink href="#collection">
            Ini adalah nama koleksi yang sangat panjang untuk mencetuskan
            elipsis
          </BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbPage>Laman Anda</BreadcrumbPage>
        </BreadcrumbItem>
      </Breadcrumb>
    </div>
  </Tab>
  <Tab value="Kod">
    ```tsx

      <BreadcrumbItem>
    ```

### Tahap Dilipat

Untuk jejak yang dalam, kekalkan tahap pertama dan dua tahap terakhir, dan lipat tahap di tengah ke dalam `BreadcrumbEllipsis`. Komponen ini hanya hiasan (disembunyikan daripada pembaca skrin); untuk membolehkan pengguna mencapai tahap yang tersembunyi, balutkannya dalam butang atau pencetus `Menu` yang menyenaraikan tahap tersebut.

<Tabs items={["Pratonton", "Kod"]} defaultValue="Pratonton">
  <Tab value="Pratonton">
    <div className="not-prose space-y-2">

          <BreadcrumbEllipsis />
