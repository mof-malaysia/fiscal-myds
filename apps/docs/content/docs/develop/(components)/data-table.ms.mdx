## Pemasangan

Tambah komponen ini ke projek anda dengan CLI shadcn. Lihat [Pemasangan](./install) untuk persediaan awal.

```package-install
npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/data-table.json
```

## Penggunaan

```ts copy title="Import"
import { DataTable } from "@/components/ui/data-table";
```

```tsx copy title="Anatomi"
export default () => <DataTable />;
```

## Contoh

### Data & Lajur

Komponen `DataTable` terutamanya ditakrifkan oleh 2 prop penting: `data` dan `columns`.

- `data` menerima array objek, di mana setiap objek mewakili baris dalam jadual.
- `columns` menerima array `ColumnDef`, di mana setiap objek mewakili lajur dalam jadual.

### Pemilihan Baris

Aktifkan mod pemilihan dengan menghantar prop `selection` kepada komponen `DataTable`. Prop `selection` menerima objek dengan sifat berikut:

- `mode`: Jenis pemilihan. Boleh sama ada `checkbox` atau `radio`.
- `onSelectionChange`: Fungsi panggilan balik yang dicetuskan apabila pemilihan berubah.
- `id_by`: Kunci dalam objek setiap baris yang mengenal pasti baris tersebut secara unik. `onSelectionChange` melaporkan baris yang dipilih menggunakan nilai ini.
- `enableRowSelection` (pilihan): `false`, atau fungsi yang menerima baris, untuk menghalang sesetengah baris daripada dipilih.

Baris yang dipilih diisi dengan Blue Wash, dan setiap baris diserlahkan dengan Well apabila dituding.
