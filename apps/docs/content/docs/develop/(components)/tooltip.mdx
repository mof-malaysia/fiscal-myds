## Installation

Add this component to your project with the shadcn CLI. See [Installation](./install) for the one-time setup.

```package-install
npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/tooltip.json
```

## Props

### Tooltip

`Tooltip` is the wrapper component which manages the tooltip's state. It is built on top of Base UI's `Tooltip.Provider` and `Tooltip.Root`. Please refer to the full API references in this [documentation](https://base-ui.com/react/components/tooltip#root).

<TypeTable
  type={{
    defaultOpen: {
      description:
        "The initial open state of the tooltip when it's first rendered.",
      type: "boolean",
    },
    open: {
      description: "Allows direct manipulation of the open state.",
      type: "boolean",
    },
    onOpenChange: {
      description: "Allows a callback to be fired when the open state changes.",
      type: "function",
    },
    delayDuration: {
      description: "The time delay before showing the tooltip when hovering.",
      type: "number",
      default: "200ms",
    },
    disableHoverablePopup: {
      description:
        "When true, prevents the user from hovering over the tooltip content.",
      type: "boolean",
    },
  }}
/>

### TooltipContent

`TooltipContent` is the "bubble" that displays the tooltip. It is built on top of Base UI's `Tooltip.Portal`, `Tooltip.Positioner` and `Tooltip.Popup`; positioning props are forwarded to the positioner. Please refer to the full API references in this [documentation](https://base-ui.com/react/components/tooltip#positioner).

<TypeTable
  type={{
    container: {
      description: "The element to portal the tooltip content into.",
      type: "HTMLElement",
      default: "document.body",
    },
    keepMounted: {
      description: "Whether to keep the tooltip content mounted in the DOM while closed.",
      type: "boolean",
      default: "false",
    },
    arrowPadding: {
      description: "Space between the arrow and the tooltip content edges.",
      type: "number",
    },
    align: {
      description: "Alignment along the tooltip's side.",
      type: "enum",
      typeDescription: "start | center | end",
      default: "center",
    },
    side: {
      description: "Preferred position of the tooltip.",
      type: "enum",
      typeDescription: "top | right | bottom | left",
      default: "top",
    },
  }}
/>

### TooltipTrigger

`TooltipTrigger` is the component where the user interacts with to show the tooltip. It is built on top of Base UI's `Tooltip.Trigger`. Use the `render` prop to render your own element as the trigger, e.g. `render={<Button />}`. Please refer to the full API references in this [documentation](https://base-ui.com/react/components/tooltip#trigger).
