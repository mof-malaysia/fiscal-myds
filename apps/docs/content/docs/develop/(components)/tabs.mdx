## Installation

Add this component to your project with the shadcn CLI. See [Installation](./install) for the one-time setup.

```bash
npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/tabs.json
```

## Usage

```ts copy title="Import"
import {
  Tabs,
  TabsList,
  TabsTrigger,
  TabsContent,
  TabsCounter,
} from "@/components/ui/tabs";
```

```tsx copy title="Anatomy"
export default () => (
  <Tabs>
    <TabsList>
      <TabsTrigger />
    </TabsList>
    <TabsContent />
  </Tabs>
);
```

## Examples

Tabs have one style: labels in Ink Secondary on a single Hairline, with the active tab in Ink and a 2px MYDS Blue underline that slides between tabs.

### Size

Use the `size` prop to change the size of the tabs. Examples of use cases for both types are outlined below:

1. **Small**: Typically used for small components or on smaller devices like mobile phones.
2. **Medium**: Commonly applied to medium or large-sized components or devices such as tablets and desktops.

## Props

### Tabs

The primary container that composes all tab components together, managing state and interactions between triggers and their content panels. It is built on top of Base UI's `Tabs.Root`.

<TypeTable
  type={{
    size: {
      description: "Sizes of the tab",
      type: "enum",
      typeDescription: "small | medium",
      default: "small",
    },
    activationMode: {
      description: "`automatic` activates a tab as soon as it receives keyboard focus; `manual` waits for Enter or Space",
      type: "enum",
      typeDescription: "automatic | manual",
      default: "automatic",
    },
  }}
/>

### TabsList

A container that houses and aligns all tab triggers, providing a consistent layout for navigation elements. It is built on top of Base UI's `Tabs.List`.

<TypeTable
  type={{
    width: {
      description: "Width of the TabsList. `full` runs the Hairline across the container; `fit` stops it at the last tab",
      type: "enum",
      typeDescription: "full | fit",
      default: "fit",
    },
  }}
/>

### TabsTrigger

Interactive element that toggles visibility of its corresponding tab panel when selected. It is built on top of Base UI's `Tabs.Tab`.

### TabsContent

The panel that displays content when its corresponding trigger is selected, hiding when another tab is activated. It has a top padding and Ink body text by default, so you rarely need to add spacing. It is built on top of Base UI's `Tabs.Panel`.

### TabsIcon

The `TabsIcon` is a wrapper component that applies consistent styling and sizing to icons within `TabsTrigger`, using context-based size variants (`small` or `medium`).

### TabsCounter

The `TabsCounter` displays a count beside the tab label as a neutral pill in tabular figures, so it does not compete with the active tab's MYDS Blue underline.
