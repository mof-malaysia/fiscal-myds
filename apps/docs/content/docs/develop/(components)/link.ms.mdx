## Pemasangan

Tambah komponen ini ke projek anda dengan CLI shadcn. Lihat [Pemasangan](./install) untuk persediaan awal.

```package-install
npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/link.json
```

## Cara Penggunaan

```tsx copy
import { Link } from "@/components/ui/link";
```

```tsx copy title="Anatomi"
export default () => (
  <Link href="/" primary>
    {/* Destinasi pautan harus dinyatakan di sini. */}
    Sistem Reka Bentuk Rasmi Malaysia
  </Link>
);
```

## Contoh

### Prop render

Sekiranya anda perlu menggunakan komponen `Link` daripada pakej yang lain, anda boleh
menggunakan prop `render` seperti berikut (Next.js sebagai contoh):

<Tabs items={["Pratonton", "Kod"]} defaultValue="Preview">
  <Tab value="Pratonton">
    <Link render={<NextLink href="#prop-render" />}>
      Custom Link
    </Link>
  </Tab>
  <Tab value="Kod">
    ```tsx 
    import { Link } from "@/components/ui/link";
    import NextLink from "next/link";

    <Link render={<NextLink href="#" />}>Custom Link</Link>
    ```

  </Tab>
</Tabs>

Anda juga boleh membina komponen sendiri dan import mengikut keperluan:

```tsx
import { Link as LinkPrimitive } from "@/components/ui/link";
import NextLink from "next/link";

export const Link = ({ href, ...props }) => (
  <LinkPrimitive render={<NextLink href={href} />} {...props} />
);
```

### Prop newTab

Prop ini menetapkan sama ada pautan dibuka dalam tab baharu dengan menggunakan `target="_blank"`.

<Tabs items={["Pratonton", "Kod"]} defaultValue="Preview">
  <Tab value="Pratonton">
    <Link href="https://digital.gov.my" newTab>Ministry of Digital</Link>
  </Tab>
  <Tab value="Kod">
    ```tsx 
    import { Link } from "@/components/ui/link";

    <Link href="https://digital.gov.my" newTab>Ministry of Digital</Link>
    ```

  </Tab>
</Tabs>

<Callout

### Primary

Prop ini digunakan untuk menetapkan warna teks pautan.

<Tabs items={["Pratonton", "Kod"]} defaultValue="Preview">
  <Tab value="Pratonton">
    <div className="space-y-2">
      <div className="flex justify-center items-center gap-2">
        <Link href="#primary" primary>Primary</Link>
        <Link href="#primary">Inherit from parent (default)</Link>
      </div>
    </div>
  </Tab>
  <Tab value="Kod">
    ```tsx 
    import { Link } from "@/components/ui/link";

    <Link href="#" primary>Primary</Link>
    <Link href="#">Inherit from parent</Link>
    ```

  </Tab>
</Tabs>

### Underline

Prop ini digunakan untuk menetapkan waktu pautan digaris bawah.

  </Tab>
</Tabs>
