## Pemasangan

Tambah komponen ini ke projek anda dengan CLI shadcn. Lihat [Pemasangan](./install) untuk persediaan awal.

```bash
npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/tabs.json
```

## Penggunaan

```ts copy title="Import"
import {
  Tabs,
  TabsList,
  TabsTrigger,
  TabsContent,
  TabsCounter,
} from "@/components/ui/tabs";
```

```tsx copy title="Anatomi"
export default () => (
  <Tabs>
    <TabsList>
      <TabsTrigger />
    </TabsList>
    <TabsContent />
  </Tabs>
);
```

## Contoh

### Saiz

Gunakan prop `size` untuk menukar saiz tab. Contoh penggunaan untuk kedua-dua jenis dihuraikan di bawah:

1.  **Small**: Biasanya digunakan untuk komponen kecil atau pada peranti yang lebih kecil seperti telefon bimbit.
2.  **Medium**: Biasanya digunakan untuk komponen atau peranti bersaiz sederhana atau besar seperti tablet dan desktop.

### Ikon

Ikon ("leading icon") berfungsi sebagai penunjuk visual yang diletakkan di tab, meningkatkan kebolehgunaan dengan memberikan pengecaman serta-merta tentang tujuan tab. Subkomponen `TabsIcon` boleh digunakan untuk tujuan tersebut. Tambahan pula, `TabsIcon` boleh diletakkan di sebelah kiri atau kanan penerangan `TabsTrigger`.

## Props

### Tabs

Bekas utama yang menggabungkan semua komponen tab, mengurus keadaan dan interaksi antara pencetus dan panel kandungannya. Ia dibina di atas `Tabs.Root` Base UI.

<TypeTable
  type={{
    size: {
      description: "Saiz tab",
      type: "enum",
      typeDescription: "small | medium",
      default: "small",
    },
    activationMode: {
      description: "`automatic` mengaktifkan tab sebaik sahaja ia menerima fokus papan kekunci; `manual` menunggu kekunci Enter atau Space",
      type: "enum",
      typeDescription: "automatic | manual",
      default: "automatic",
    },
  }}
/>

### TabsList

Bekas yang menempatkan dan menyusun semua pencetus tab, menyediakan susun atur yang konsisten untuk elemen navigasi. Ia dibina di atas `Tabs.List` Base UI.

<TypeTable
  type={{
    width: {
      description: "Lebar TabsList. `full` memanjangkan Hairline merentasi bekas; `fit` menghentikannya pada tab terakhir",
      type: "enum",
      typeDescription: "full | fit",
      default: "fit",
    },
  }}
/>

### TabsTrigger

Elemen interaktif yang memaparkan panel tab yang sepadan apabila dipilih. Ia dibina di atas `Tabs.Tab` Base UI.

### TabsContent

Panel yang memaparkan kandungan apabila pencetus yang sepadan dipilih, dan disembunyikan apabila tab lain diaktifkan. Secara lalai, ia mempunyai padding atas dan teks Ink, jadi anda jarang perlu menambah jarak sendiri. Ia dibina di atas `Tabs.Panel` Base UI.

### TabsIcon

`TabsIcon` ialah komponen pembalut yang menerapkan gaya dan saiz yang konsisten kepada ikon dalam `TabsTrigger`, menggunakan variasi saiz berdasarkan konteks (`small` atau `medium`).

### TabsCounter

`TabsCounter` memaparkan bilangan di sebelah label tab sebagai pil neutral dengan angka tabular, supaya ia tidak bersaing dengan garis bawah MYDS Blue pada tab aktif.
