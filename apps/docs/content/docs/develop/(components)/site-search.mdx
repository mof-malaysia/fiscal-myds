## Installation

Add this component to your project with the shadcn CLI. See [Installation](./install) for the one-time setup.

```package-install
npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/marketing/styles/default/site-search.json
```

## Usage

```ts copy title="Import"
import { SiteSearch } from "@/components/ui/site-search";
```

```tsx copy title="Anatomy"
export default () => <SiteSearch action="/search" />;
```

SiteSearch renders a `<form role="search">` with a label (hidden unless `showLabel`), a search field and a Search button. By default it submits a GET request to `action` with the query as `?q=…`, so it works before JavaScript loads.

### Which search to use

- **Search this site** (results on their own page): `SiteSearch`.
- **Suggestions while typing**: compose `Autocomplete`.
- **Filter a list already on screen** (a table, a grid of icons): a search `Input` with a search icon, like `WorkQueue`.
- **Go to anything in an officer app**: the `Command` palette, opened with ⌘K or `DeskSearchTrigger`.

## Examples

### Handled in the page

Pass `onSearch` to handle the query yourself, for example with your router. The form's own submit is prevented.

```tsx copy
<SiteSearch onSearch={(query) => router.push(`/search?q=${encodeURIComponent(query)}`)} />
```

### Hero size and keyboard shortcut

Use `size="large"` in a hero. `shortcut` lets people press <kbd>/</kbd> anywhere on the page to jump to the field, and shows the key while the field is empty.
