## Installation

Add this component to your project with the shadcn CLI. See [Installation](./install) for the one-time setup.

```package-install
npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/textarea.json
```

## Usage

```ts copy title="Import"
import { TextArea } from "@/components/ui/textarea";
```

```tsx copy title="Anatomy"
export default () => (
  <TextArea
    placeholder="Placeholder text displayed when the text area is empty."
    size={"small"}
    disabled={false}
  />
);
```

## Examples

### Size

Controls the input field's size variant. Supports `small`, `medium`, or `large`.

<Tabs items={["Preview", "Code"]} defaultValue="Preview">
  <Tab value="Preview">
  <div className="space-y-2">
  <div className="flex flex-col justify-center items-center h-fit gap-5">
      <TextArea size="small" placeholder="Enter your text for your small TextArea."/>
      <TextArea size="medium" placeholder="Enter your text for your medium TextArea."/>
      <TextArea size="large"placeholder="Enter your text for your large TextArea." />
      </div>

  </div>
  </Tab>
  <Tab value="Code">
  ```tsx 
import { TextArea } from "@/components/ui/textarea";

/\*_ Size props_/

<TextArea size="small" placeholder="Enter your text for your small TextArea."/>
<TextArea size="medium" placeholder="Enter your text for your medium TextArea."/>
<TextArea size="large"placeholder="Enter your text for your large TextArea." />
```
  </Tab>
</Tabs>

### Disabled

The `disabled` props can be used to disable user input and applies a visual styling to indicate the field cannot be edited.
