## Pemasangan

Tambah komponen ini ke projek anda dengan CLI shadcn. Lihat [Pemasangan](./install) untuk persediaan awal.

```package-install
npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/accordion.json
```

## Penggunaan

```ts copy title="Import"
import {
  AccordionTrigger,
  AccordionContent,
  Accordion,
  AccordionItem,
} from "@/components/ui/accordion";
```

```tsx copy title="Anatomi"
export default () => (
  <Accordion>
    <AccordionItem>
      <AccordionTrigger></AccordionTrigger>
      <AccordionContent></AccordionContent>
    </AccordionItem>
  </Accordion>
);
```

## Contoh

### Jenis

Gunakan prop `type` untuk menukar cara kandungan dipaparkan!

- `single`: hanya benarkan satu kandungan ditunjukkan pada satu masa

- `multiple`: benarkan beberapa kandungan ditunjukkan pada masa yang sama.

### Boleh Dilipat

<Tabs items={["Pratonton", "Kod"]} defaultValue="Pratonton">

<Accordion type="single" defaultValue="item-1" collapsible={false}>
  {items.default}
</Accordion>

### Dilumpuh

Prop `disabled` wujud dalam kedua-dua komponen `Accordion` dan `AccordionItem`.

Menetapkan `disabled` kepada `true` dalam `Accordion` akan melumpuhkan semua komponen `AccordionItem`, manakala dalam `AccordionItem` akan melumpuhkan `AccordionItem` yang berkenaan.

<Tabs items={["Pratonton", "Kod"]} defaultValue="Pratonton">

    <Accordion type="single" defaultValue="item-1">
      {items.disabled}
    </Accordion>
