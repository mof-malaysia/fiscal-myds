## Pemasangan

Tambah komponen ini ke projek anda dengan CLI shadcn. Lihat [Pemasangan](./install) untuk persediaan awal.

```package-install
npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/tooltip.json
```

## Contoh-contoh

### Keadaan Tidak Terkawal vs Terkawal

Untuk menggunakan komponen ini dalam keadaan tidak terkawal, tetapkan prop `defaultOpen` kepada keadaan awal input.

Untuk menggunakan komponen dalam keadaan terkawal, gunakan prop `open` dan `onOpenChange` untuk mengendalikan keadaan secara programatik.

  </Tooltip>
  </Tab>

Komponen `Tooltip` dibina di atas `Tooltip.Provider` dan `Tooltip.Root` daripada Base UI. Sila rujuk senarai API lengkap dalam [dokumentasi ini](https://base-ui.com/react/components/tooltip#root).

Komponen `TooltipContent` ini dibina di atas `Tooltip.Portal`, `Tooltip.Positioner` dan `Tooltip.Popup` daripada Base UI; prop kedudukan dihantar ke positioner. Sila rujuk senarai penuh API di [dokumentasi ini](https://base-ui.com/react/components/tooltip#positioner).

### TooltipTrigger

`TooltipTrigger` membolehkan pengguna untuk berinteraksi atas tujuan menunjukkan "tooltip". Komponen ini dibina menggunakan `Tooltip.Trigger` daripada Base UI. Gunakan prop `render` untuk memaparkan elemen anda sendiri sebagai pencetus, contohnya `render={<Button />}`. Sila rujuk senarai penuh API di [dokumentasi ini](https://base-ui.com/react/components/tooltip#trigger).
