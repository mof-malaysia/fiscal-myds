## Penggunaan

### Penggunaan Mudah

Untuk penggunaan mudah, `AutoToast` boleh digunakan secara terus untuk mengendalikan kes penggunaan biasa.

```tsx copy title="layout.tsx"
import { AutoToast } from "@/components/ui/toast";

// Letakkan komponen ini di bahagian atas dalam DOM
<AutoToast />;
```

```tsx copy title="Anatomi"
// Kemudian, terbitkan atau hantar peristiwa baru kepada Toast
import { useToast } from "@/lib/myds/hooks";

export default () => {
  const { toast } = useToast();
  return (
    <button
      onClick={() => {
        toast({
          variant: "message",
          title: "Hello, world!",
          description: "this is a message toast description",
        });
      }}
    >
      Message
    </button>
  );
};
```

### Penggunaan Lanjutan

Sebagai alternatif kepada `AutoToast`, komponen `Toast` boleh disusun secara manual untuk kawalan yang lebih. Baca toast yang aktif dengan `useToastManager()` dan paparkan `ToastRoot` untuk setiap satu, dengan menghantar objek `toast`. `ToastTitle` dan `ToastDescription` memaparkan `title` dan `description` toast secara lalai.

```tsx copy
import {
  ToastRoot,
  ToastIcon,
  ToastProgress,
  ToastProvider,
  ToastViewport,
  ToastTitle,
  ToastDescription,
  ToastClose,
  useToastManager,
} from "@/components/ui/toast";

// Memaparkan setiap toast yang aktif
const Toasts = () => {
  const { toasts } = useToastManager();

  return toasts.map((toast) => (
    <ToastRoot key={toast.id} toast={toast}>
      <ToastIcon />
      <div className="space-y-1">
        <ToastTitle />
        {toast.description && <ToastDescription />}
      </div>
      <ToastClose />
      <ToastProgress />
    </ToastRoot>
  ));
};

// Letakkan provider di bahagian atas dalam DOM
export default ({ children }: { children: React.ReactNode }) => (
  <ToastProvider>
    {children}
    <ToastViewport>
      <Toasts />
    </ToastViewport>
  </ToastProvider>
);
```

Di dalam `ToastProvider` yang disusun secara manual, tambah toast dengan `useToastManager().add()`. Medan `type` menentukan varian. `useToast().toast()` hanya sampai kepada `AutoToast`.

```tsx copy title="Anatomi"
import { useToastManager } from "@/components/ui/toast";

// Tambah toast dari mana-mana komponen di dalam ToastProvider
const SaveButton = () => {
  const toastManager = useToastManager();
  return (
    <button
      onClick={() =>
        toastManager.add({
          type: "success",
          title: "Saved",
          description: "Your changes have been saved.",
        })
      }
    >
      Save
    </button>
  );
};
```

Secara lalai, sehingga 3 toast dipaparkan pada satu masa. Tukar had ini dengan prop `limit` pada `ToastProvider`.

## Contoh

### Variant

5 varian toast tersedia: `message`, `info`, `success`, `warning` dan `error`. Contoh penggunaan adalah:

1. Varian `success` boleh digunakan untuk menunjukkan tindakan yang berjaya seperti membuat permintaan baharu atau menghantar borang.
2. Varian `warning` boleh memberi amaran kepada pengguna untuk mengambil perhatian, sering digunakan untuk peringatan atau tindakan yang memerlukan perhatian, seperti melaporkan spam.
3. Varian `info` boleh memberikan maklumat tambahan untuk memastikan pengguna sentiasa maklum.
4. Varian `error` boleh digunakan untuk memberitahu pengguna tentang ralat yang memerlukan penyelesaian sebelum meneruskan.

## Props

### ToastProvider
`ToastProvider` dibina di atas `Toast.Provider` daripada Base UI. Gunakan `limit` untuk menetapkan bilangan toast yang dipaparkan pada satu masa (lalai `3`) dan `timeout` untuk menetapkan masa tutup automatik lalai. Sila rujuk kepada rujukan API dalam [dokumentasi ini](https://base-ui.com/react/components/toast#provider).

### ToastViewport
`ToastViewport` dibina di atas `Toast.Viewport` daripada Base UI. Paparkan elemen `ToastRoot` anda sebagai anaknya. Sila rujuk kepada rujukan API dalam [dokumentasi ini](https://base-ui.com/react/components/toast#viewport).

### ToastRoot
`ToastRoot` dibina di atas `Toast.Root` daripada Base UI. Ia memerlukan objek `toast` yang dikembalikan oleh `useToastManager()`. Sila rujuk kepada rujukan API dalam [dokumentasi ini](https://base-ui.com/react/components/toast#root).

### ToastTitle
`ToastTitle` dibina di atas `Toast.Title` daripada Base UI. Sila rujuk kepada rujukan API dalam [dokumentasi ini](https://base-ui.com/react/components/toast#title).

### ToastDescription
`ToastDescription` dibina di atas `Toast.Description` daripada Base UI. Sila rujuk kepada rujukan API dalam [dokumentasi ini](https://base-ui.com/react/components/toast#description).

### ToastClose
`ToastClose` dibina di atas `Toast.Close` daripada Base UI. Sila rujuk kepada rujukan API dalam [dokumentasi ini](https://base-ui.com/react/components/toast#close).

### useToastManager
`useToastManager()` mengembalikan `{ toasts, add, close, update, promise }`. Ia mesti dipanggil di dalam `ToastProvider`.
