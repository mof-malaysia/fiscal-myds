## Installation

Add this component to your project with the shadcn CLI. See [Installation](./install) for the one-time setup.

```package-install
npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/label.json
```

## Usage

```ts copy title="Import"
import { Label } from "@/components/ui/label";
import { Checkbox } from "@/components/ui/checkbox";
import { Toggle, ToggleThumb } from "@/components/ui/toggle";
```

```tsx copy title="Anatomy"
export default () => (
  <>
    <div className="flex items-center justify-between">
      <Label htmlFor="checkbox">Auto-delete notifications</Label>
      <Checkbox id="checkbox"></Checkbox>
    </div>
    <div className="flex items-center justify-between">
      <Label htmlFor="toggle">Enable 2FA security?</Label>
      <Toggle id="toggle">
        <ToggleThumb />
      </Toggle>
    </div>
  </>
);
```
