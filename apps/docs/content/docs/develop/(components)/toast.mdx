## Usage

### Simple Usage

For simple usage, `AutoToast` can be used directly. It is a pre-assembled, simplified version of the `Toast` that handles common use cases.

```tsx copy title="layout.tsx"
import { AutoToast } from "@/components/ui/toast";

// Put the component high up in the DOM tree
<AutoToast />;
```

```tsx copy title="Anatomy"
// Then, publish or emit a new event to the Toast
import { useToast } from "@/lib/myds/hooks";

export default () => {
  const { toast } = useToast();
  return (
    <button
      onClick={() => {
        toast({
          variant: "message",
          title: "Hello, world!",
          description: "this is a message toast description",
        });
      }}
    >
      Message
    </button>
  );
};
```

### Advanced Usage

Instead of using `AutoToast`, the `Toast` component can be assembled manually for more control. Read the active toasts with `useToastManager()` and render a `ToastRoot` for each one, passing the `toast` object. `ToastTitle` and `ToastDescription` render the toast's `title` and `description` by default.

```tsx copy
import {
  ToastRoot,
  ToastIcon,
  ToastProgress,
  ToastProvider,
  ToastViewport,
  ToastTitle,
  ToastDescription,
  ToastClose,
  useToastManager,
} from "@/components/ui/toast";

// Renders every active toast
const Toasts = () => {
  const { toasts } = useToastManager();

  return toasts.map((toast) => (
    <ToastRoot key={toast.id} toast={toast}>
      <ToastIcon />
      <div className="space-y-1">
        <ToastTitle />
        {toast.description && <ToastDescription />}
      </div>
      <ToastClose />
      <ToastProgress />
    </ToastRoot>
  ));
};

// Put the provider high up in the DOM tree
export default ({ children }: { children: React.ReactNode }) => (
  <ToastProvider>
    {children}
    <ToastViewport>
      <Toasts />
    </ToastViewport>
  </ToastProvider>
);
```

Inside a manually assembled `ToastProvider`, add toasts with `useToastManager().add()`. The `type` field selects the variant. `useToast().toast()` only reaches `AutoToast`.

```tsx copy title="Anatomy"
import { useToastManager } from "@/components/ui/toast";

// Add a toast from any component inside ToastProvider
const SaveButton = () => {
  const toastManager = useToastManager();
  return (
    <button
      onClick={() =>
        toastManager.add({
          type: "success",
          title: "Saved",
          description: "Your changes have been saved.",
        })
      }
    >
      Save
    </button>
  );
};
```

By default, up to 3 toasts are visible at once. Change this with the `limit` prop on `ToastProvider`.

## Examples

### Variant

5 variants of toast are availablle: `message`, `info`, `success`, `warning` and `error`. The examples of use cases are:

1. `success` variant can be used to indicates a successful action such as creating a new request or submitting a form.
2. `warning` variant can alert the users to take notice, often used for reminders or actions that require attention, such as reporting spam.
3. `information` variant can provides additional details to keep user informed.
4. `error` variant can be used to notify the user of an error that requires resolution before proceeding.

## Props

### ToastProvider
`ToastProvider` is built on Base UI's `Toast.Provider`. Use `limit` to set how many toasts are visible at once (default `3`) and `timeout` to set the default auto-dismiss time. Please refer to the API references in this [documentation](https://base-ui.com/react/components/toast#provider).

<TypeTable
  type={{
    limit: {
      description: "Maximum number of toasts visible at once",
      type: "number",
      default: "3",
    },
    timeout: {
      description: "Default time (ms) before a toast is dismissed",
      type: "number",
      default: "5000",
    },
  }}
/>

### ToastViewport
`ToastViewport` is built on Base UI's `Toast.Viewport`. Render your `ToastRoot` elements as its children. Please refer to the API references in this [documentation](https://base-ui.com/react/components/toast#viewport).

### ToastRoot
`ToastRoot` is built on Base UI's `Toast.Root`. It requires the `toast` object returned by `useToastManager()`. Please refer to the API references in this [documentation](https://base-ui.com/react/components/toast#root).

### ToastTitle
`ToastTitle` is built on Base UI's `Toast.Title`. Please refer to the API references in this [documentation](https://base-ui.com/react/components/toast#title).

### ToastDescription
`ToastDescription` is built on Base UI's `Toast.Description`. Please refer to the API references in this [documentation](https://base-ui.com/react/components/toast#description).

### ToastClose
`ToastClose` is built on Base UI's `Toast.Close`. Please refer to the API references in this [documentation](https://base-ui.com/react/components/toast#close).

### useToastManager
`useToastManager()` returns `{ toasts, add, close, update, promise }`. It must be called inside `ToastProvider`.
