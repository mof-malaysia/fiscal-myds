## Pemasangan

Tambah komponen ini ke projek anda dengan CLI shadcn. Lihat [Pemasangan](./install) untuk persediaan sekali sahaja.

```package-install
npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/marketing/styles/default/site-search.json
```

## Penggunaan

```ts copy title="Import"
import { SiteSearch } from "@/components/ui/site-search";
```

```tsx copy title="Anatomi"
export default () => <SiteSearch action="/carian" />;
```

SiteSearch memaparkan `<form role="search">` dengan label (tersembunyi kecuali `showLabel`), medan carian dan butang Cari. Secara lalai ia menghantar permintaan GET ke `action` dengan pertanyaan sebagai `?q=…`, jadi ia berfungsi sebelum JavaScript dimuatkan.

### Carian mana yang patut digunakan

- **Cari dalam laman ini** (hasil di halaman sendiri): `SiteSearch`.
- **Cadangan semasa menaip**: gubah `Autocomplete`.
- **Tapis senarai yang sudah dipaparkan** (jadual, grid ikon): `Input` carian dengan ikon carian, seperti `WorkQueue`.
- **Pergi ke mana-mana dalam aplikasi pegawai**: palet `Command`, dibuka dengan ⌘K atau `DeskSearchTrigger`.

## Contoh

### Dikendalikan dalam halaman

Hantar `onSearch` untuk mengendalikan pertanyaan sendiri, contohnya dengan penghala anda. Penghantaran borang dihalang.

```tsx copy
<SiteSearch onSearch={(query) => router.push(`/carian?q=${encodeURIComponent(query)}`)} />
```

### Saiz hero dan pintasan papan kekunci

Gunakan `size="large"` dalam hero. `shortcut` membolehkan pengguna menekan <kbd>/</kbd> di mana-mana pada halaman untuk terus ke medan, dan menunjukkan kekunci semasa medan kosong.
