## Installation

Add this component to your project with the shadcn CLI. See [Installation](./install) for the one-time setup.

```package-install
npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/breadcrumb.json
```

## Usage

```ts copy title="Import"
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbSeparator,
  BreadcrumbPage,
  BreadcrumbEllipsis,
} from "@/components/ui/breadcrumb";
```

```tsx copy title="Anatomy"
export default () => (
  <Breadcrumb>
    <BreadcrumbItem>
      <BreadcrumbLink />
      <BreadcrumbPage />
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbEllipsis />
    </BreadcrumbItem>
  </Breadcrumb>
);
```

## Examples

### Link vs Page

`BreadcrumbLink` is used for the parent page, while `BreadcrumbPage` is used for the current page. The current page is typically not clickable.

### Ellipsis Crumb

Crumbs that are too long will be truncated with an ellipsis. The maximum width limit is `200px`. The full name is kept in the `title` tooltip, so users can hover over the crumb to see it.

<Tabs items={["Preview", "Code"]} defaultValue="Preview">
  <Tab value="Preview">
    <div className="not-prose space-y-2">
      <Breadcrumb>
        <BreadcrumbItem>
          <BreadcrumbLink href="#home">Home</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbLink href="#collection">
            This is a very long collection name to trigger the ellipsis
          </BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbPage>Your Page</BreadcrumbPage>
        </BreadcrumbItem>
      </Breadcrumb>
    </div>
  </Tab>

### Collapsed Levels

For deep trails, keep the first level and the last two, and collapse the middle into `BreadcrumbEllipsis`. It is decorative on its own (hidden from screen readers); to let people reach the hidden levels, wrap it in a button or a `Menu` trigger that lists them.

        </BreadcrumbItem>

          <BreadcrumbEllipsis />
        </BreadcrumbItem>
        <BreadcrumbSeparator />
