## Installation

Add this component to your project with the shadcn CLI. See [Installation](./install) for the one-time setup.

```package-install
npx shadcn@latest add https://mof-malaysia.github.io/fiscal-myds/registry/ui/styles/default/toggle.json
```

## Usage

```ts copy title="Import"
import { Toggle, ToggleThumb } from "@/components/ui/toggle";
```

```tsx copy title="Anatomy"
export default () => (
  <Toggle>
    <ToggleThumb />
  </Toggle>
);
```

### Controlled Toggle

Toggle can be handled by Controlled Method

<Tabs items={["Preview", "Code"]} defaultValue="Preview">
  <Tab value="Preview">
    <div className="space-y-2">
        <div className="flex justify-center items-center h-fit ">
            <ControlledToggle/>
        </div>
    </div>
  </Tab>
  <Tab value="Code">
```tsx
import { Toggle, ToggleThumb } from "@/components/ui/toggle";

const ControlledToggle = () => {
const [isChecked, setIsChecked] = React.useState(false);
return (

<div className="flex flex-col items-center justify-center">
  <p>Current state: {isChecked ? "On" : "Off"}</p>
  <Toggle checked={isChecked} onCheckedChange={setIsChecked}>
    <ToggleThumb />
  </Toggle>
</div>
); };

````

  </Tab>
</Tabs>
